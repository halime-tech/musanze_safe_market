# Musanze Safe Market Field Inspection Prototype

## SWE 3409 - Mobile Application Development
### Assignment 1

A React Native and Expo mobile application prototype for the fictional Musanze Safe Markets field inspection pilot.

## Features

- Market catalog with at least six fictional zones or stalls
- Vendor inspection form
- Form validation
- Bottom tab navigation
- Inspection Details stack navigation
- Camera and gallery image selection
- Image preview, replacement, and removal
- Permission-denied and cancellation handling
- Inspection review screen
- Group verification code
- In-memory inspection records

## Technologies

- React Native
- Expo
- TypeScript
- React Navigation
- Expo Camera and/or Expo ImagePicker
- React Hooks
- Flexbox
